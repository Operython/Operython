Extensión Oficial (v1.0)

Operython Scripts

¿Usas Google Chrome u otro navegador basado en Chromium (Edge, Brave, Opera)? Instala la extensión oficial Operython Scripts para importar y ejecutar los mismos paquetes de scripts web fuera de Operython GX.

🔌 Cómo instalar la extensión en Google Chrome:
  1. Descarga el archivo Operython scripts.zip y descomprímelo en una carpeta que no vayas a borrar (por ejemplo, dentro de Documentos).
  2. Abre Google Chrome y escribe en la barra de direcciones: chrome://extensions.
  3. Activa el interruptor Modo de desarrollador que aparece en la esquina superior derecha.
  4. Haz clic en el botón Cargar descomprimida (arriba a la izquierda) y selecciona la carpeta que extrajiste (la que contiene el archivo manifest.json).
🧩 Descargar Extensión (.zip)
Complementos

Scripts Web

Personaliza tus sitios favoritos con paquetes de scripts listos para usar. Activa o desactiva cada función individualmente desde el panel 🧩 de Operython.

📂 Opción A — Instalar en Operython GX:
  1. Descarga el archivo .zip del script que quieras abajo.
  2. Ve a Documentos → entra en Operython system → abre la carpeta scripts_web.
  3. Pega el .zip adentro y haz clic derecho → Extraer aquí (debe quedar la carpeta con su script.txt y assets).
  4. En Operython GX, abre el panel 🧩 y pulsa Actualizar lista y páginas.

🧩 Opción B — Cargar en la extensión Operython Scripts (Chrome / Edge):
  1. Descarga el archivo .zip del script que quieras abajo y descomprímelo en una carpeta.
  2. Haz clic en el icono de la extensión Operython Scripts en la barra superior de tu navegador.
  3. Pulsa el botón para Importar (o selecciona el archivo script.txt de la carpeta que extrajiste) y recarga la página web para aplicar los cambios.

Términos de Privacidad y Condiciones

Última actualización: Noviembre de 2026 • Ecosistema Operython GX

1. Aceptación de los Términos

Al descargar, descomprimir, instalar o ejecutar cualquiera de los programas, extensiones o paquetes pertenecientes al ecosistema Operython GX (incluyendo el navegador Operython system, la extensión Operython Scripts y los complementos de la carpeta scripts_web), usted reconoce haber leído, comprendido y aceptado de forma automática e irrevocable la totalidad de los presentes Términos de Privacidad y Condiciones de Uso. Si no está de acuerdo con alguna de estas disposiciones, deberá abstenerse de instalar o utilizar el software y eliminar todos los archivos asociados de su equipo.

2. Arquitectura Local y Cero Telemetría

Operython GX está diseñado bajo una filosofía estricta de privacidad local (Local-First). El software no posee servidores centrales de recolección de datos, no utiliza sistemas de analítica externa, ni envía información de diagnóstico, métricas de uso, direcciones IP o hábitos de navegación a los desarrolladores ni a terceros. Toda su actividad permanece exclusivamente dentro de su computadora personal.

La totalidad de sus preferencias —incluyendo pestañas abiertas en los workspaces de Juegos e Investigación, historial de navegación, registro de descargas, accesos rápidos, rutas de fondos de pantalla, pistas de audio locales y el estado de activación de los scripts— se almacena únicamente en el archivo local config_maestra_operython.json y en la carpeta de almacenamiento persistente dentro de su directorio de usuario en Windows.

3. Motores de Renderizado y Conexiones a Terceros

Para mostrar contenido web, Operython GX utiliza los motores de renderizado integrados Qt WebEngine (basado en Chromium) y Microsoft Edge WebView2 como respaldo automático para contenido multimedia o transmisiones en vivo. Al visitar sitios web externos (como Google, YouTube, Discord, Spotify, Scratch o Poki) a través del navegador o de sus paneles laterales, dichos sitios aplicarán sus propias políticas de privacidad, cookies y términos de servicio, sobre los cuales Operython GX no ejerce control ni responsabilidad.

Asimismo, para obtener los iconos visuales (favicons) de los accesos directos configurados por el usuario, el navegador realiza consultas directas al servicio público de favicons de Google utilizando únicamente el dominio solicitado.

4. Sistema de Scripts Web y Seguridad

El módulo Scripts Web (tanto en Operython GX como en la extensión Operython Scripts) opera bajo un lenguaje declarativo restringido. Por razones de seguridad, los archivos script.txt no permiten ejecutar código Python ni JavaScript arbitrario, no pueden realizar peticiones de red externas ni capturar pulsaciones de teclado o formularios. Su alcance se limita a modificaciones visuales (ocultar/mostrar selectores CSS, cambiar estilos permitidos, insertar imágenes locales de la carpeta assets o bloquear redirecciones externas) únicamente en los dominios explícitamente autorizados por el usuario.

Aun así, el usuario es el único responsable de verificar el origen y contenido de los paquetes .txt o carpetas que decida importar o descomprimir dentro de scripts_web.

5. Bloqueador de Anuncios (Adblock) y Responsabilidad del Usuario

Operython GX incorpora un filtro visual de publicidad diseñado para mejorar la experiencia de lectura y rendimiento, manteniendo visibles aquellos elementos identificados como eventos o avisos comunitarios, y permitiendo al usuario desactivarlo de forma general o por sitio web. El uso de esta herramienta queda bajo la entera discreción y responsabilidad del usuario respecto a los términos de uso de las plataformas que visite.

6. Descargas, Archivos Locales y Dependencias

Durante la primera ejecución, el script lanzador (.bat) crea un entorno virtual aislado de Python (op_env) en su carpeta Documentos y descarga desde repositorios oficiales (PyPI, Microsoft y NuGet) las librerías necesarias para su funcionamiento (como PySide6, pythonnet y WebView2). Operython GX no se hace responsable por archivos, ejecutables o contenido multimedia que el usuario descargue desde Internet utilizando el gestor integrado o herramientas de terceros.

7. Exclusión de Garantías y Modificaciones

El software se entrega "tal cual" (AS IS), sin garantías expresas ni implícitas de ningún tipo, incluyendo disponibilidad ininterrumpida o compatibilidad con todos los sitios web de terceros.
